## 📌 О проекте

**«Моя Ферма»** — это веб-приложение для автоматизации учета в малых и средних фермерских хозяйствах. Система заменяет бумажные журналы и Excel-таблицы, предоставляя централизованное хранение данных о поголовье, кормах и ветеринарных обработках.

### Основные возможности

- **Учет животных**: добавление, редактирование, удаление, фильтрация по виду и статусу, автоматический расчет возраста, история веса.
- **Учет кормов**: приход/расход, конвертация единиц измерения (кг, тонна, мешок, рулон), контроль минимальных запасов, график движения за 7 дней.
- **Ветеринарные обработки**: планирование прививок, цветовая индикация срочности, отметка выполнения с автоповтором, напоминания.
- **Дашборд**: сводная статистика, список предстоящих прививок, корма на исходе, последние операции.
- **Администрирование**: управление пользователями, назначение администраторов, каскадное удаление данных.
- **Демо-режим**: предзаполненный аккаунт для ознакомления без регистрации.

### Целевая аудитория

- Владельцы и работники малых фермерских хозяйств (20–100 голов КРС)
- Пользователи без специальной ИТ-подготовки
- Ветеринарные специалисты, обслуживающие несколько хозяйств
